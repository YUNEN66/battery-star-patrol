# 电池星巡

一款离线友好、以中文为主的电池状态查看器：Windows 桌面端读取 Windows 电池报告，Android 通过可安装的 PWA 展示浏览器和厂商实际开放的数据。界面与图标均为原创作品。

## 能力与数据边界

| 信息 | Windows 笔记本 | Android |
|---|---|---|
| 当前电量、充电状态 | 从 Windows CIM / 电池报告读取（由系统提供时） | 只在浏览器开放 `navigator.getBattery()` 时读取 |
| 电池健康度估算 | 满充容量 ÷ 设计容量，取自 `powercfg /batteryreport /xml` | Android 通用应用接口通常不开放，不从当前电量推算 |
| 满充容量、设计容量 | 以 Windows 报告中以 mWh 记录的值显示 Wh | 除非设备厂商在系统中显示，否则暂不可读 |
| 循环次数 | 单块电池的报告字段；报告不提供时标为暂不可读 | 不假定系统会开放 |
| 温度 | 不读取；本版本没有可靠的系统温度接口 | 不读取 |
| 台式机 / 无电池设备 | 显示未检测到电池，不计算健康度 | 显示系统或浏览器实际开放的信息 |

健康度是由系统报告容量得出的估算，不是官方认证结果；用于 UI 展示时最高限制为 100%。系统原始满充容量与设计容量仍按报告原值展示，不会覆盖或调整。当满充容量略高于标称设计容量时，健康度显示 100%，并说明这只是报告容量与标称值的差异，不代表电池状态超过新电池。部分电池报告可能暂时没有容量、循环或电量字段；此时应用会如实标注不可读。多个电池的容量会合并计算，循环次数仅对单块电池展示，避免错误地相加。

Android 自带设置或厂商的电池诊断页面可能提供更多信息。PWA 不申请后台电池权限；也不需要安装 APK。此仓库不包含原生 Android Gradle 工程。

## Windows 桌面

### 启动

1. 在 Windows 10 或 11 上安装 Microsoft Edge。
2. 双击 `start-windows.ps1`，或使用桌面上的“电池星巡”快捷方式。
3. 应用会启动只绑定到 `127.0.0.1` 的本机服务，并在 Edge 应用窗口中打开。服务仅在本机提供静态文件和当前电池报告，不接受写入数据，不向网络上传数据。

PowerShell 使用系统自带的 Windows PowerShell 5.1，无需 Node.js、.NET SDK 或依赖下载。启动脚本只对该项目进程应用 `-ExecutionPolicy Bypass`，不改动系统执行策略。

### Windows 数据来源

电池容量从 `powercfg /batteryreport /xml` 临时生成的系统报告读取；当前电量和充电状态从 `Win32_Battery` CIM 信息读取。临时 XML 文件在读取后删除，序列号不会被读取或保存。`Win32_Battery` 未报告电量时不会用报告近似值填充；不支持的容量字段保持不可读。

## Android 安装

1. 将此项目根目录中的文件发布到提供 **HTTPS** 的静态站点，例如 GitHub Pages。
2. 在 GitHub 仓库的 **Settings → Pages** 中选择从分支发布，选定默认分支和仓库根目录（`/`）。
3. 等待 HTTPS 页面发布完成后，在 Android Chrome 中打开，再从浏览器菜单选择“安装应用”或“添加到主屏幕”。
4. 首次访问后可离线打开界面。Android 电池健康度依设备厂商开放情况而异，不可读时查看“设置 → 电池”或厂商诊断页面，或录入厂商明确给出的容量作手动参考。

手动容量保存到当前浏览器的 `localStorage`；清除浏览器站点数据或点击“清除记录”可移除。手填估算始终标注为手动数据，不覆盖 Windows 实测信息。

## 开发与发布

- 不需要安装依赖。Windows 可双击项目根目录的 `start-windows.ps1`；Android 通过 GitHub Pages 等 HTTPS 静态托管运行。
- Windows 快捷方式和封面由项目环境工具创建在当前用户桌面，不随源代码部署。
- 首次访问后，service worker 缓存界面静态资源；`/api/battery` 不缓存。
- 页面仅从本地提供的静态文件和 Windows 本机接口加载；无账号、分析、遥测、广告或第三方资源依赖。
- 本项目尚未选择开源许可证；复用、分发前请先由项目维护者选定合适的许可证。

## 项目结构

```text
assets/              原创矢量图标与封面，以及应用 PNG / ICO
index.html           中文单页应用
styles.css           霓虹都市主题和响应式布局
app.js               电池读取、手动估算与 PWA 安装交互
manifest.json        PWA 安装信息
service-worker.js    离线静态资源缓存
server.ps1           仅绑定 Windows 本机回环地址的文件与电池服务
start-windows.ps1    Windows 一键启动脚本
```
